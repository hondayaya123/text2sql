║  向量搜尋 qa type chunks，top_k=3, min_rating=4             ║

║    → 仍需完整走 Phase 2                                     ║
║                                                             ║
║  未命中 / time_sensitive：                                   ║
║    → 完整走 Phase 2                                         ║

║ Phase 2: 知識收集（一次搜尋，分類組裝）                       ║
║                                                             ║
║  Step 2a: 統一向量搜尋                                      ║

║    從 joins[].metadata.tables 和                            ║

║    → 檢查是否都有 table chunk 命中                           ║
║    → 缺少的表 → describe_table(table_name) 即時補充         ║
║                                                             ║
║  Step 2c: 全域規則注入                                      ║
║    永遠附加 global_rules（不需要搜尋，固定內容）              ║
║                                                             ║
║  Step 2d: 組裝最終 Context                                  ║

║                                                             ║

║                                                             ║
║  ├─ 成功 + 有資料 → Phase 5                                 ║

║  └─ 失敗（SQL 錯誤）                                        ║
║      → 分析錯誤訊息:                                        ║
║        column "xxx" does not exist                           ║

║          → 確認表名 → 修正 SQL                              ║

║          → 修正語法 → 重試                                  ║

║      → 3 次都失敗 → 告知使用者，附上 SQL 和錯誤供參考        ║
